# Nutriband Inc. (Nasdaq: NTRB): investor relations design concept

An independent design concept for an investor relations page. It is **not** the official Nutriband website and is not affiliated with, endorsed by, or maintained by Nutriband Inc. The official investor relations page is https://www.nutriband.com/investors.

Figures are assembled from the company's public SEC filings (10-K for the year ended January 31, 2026; 10-Q for the quarter ended July 31, 2026; 8-Ks) and each is linked beside the figure. Verify every figure against the company's official SEC filings.

The page is a single self-contained `index.html` plus the logo files in `img/`.
